# 污水接管意願管理平台 (Sewage Connection Management Platform)

本平台由 **黎明工程顧問有限公司 (環工一組)** 開發與維護，專用於污水下水道巷弄用戶接管之意願調查與試水資料管理。

## 📋 單位資訊
- **所屬單位**：黎明工程顧問有限公司 (環工一組)
- **聯絡人**：陳煥清
- **服務地點**：台中市

## 🌟 主要功能
- **住戶端**：填寫接管意願（前巷/後巷/側巷）、上傳現場照片、查看區域統計。
- **廠商端**：回報現場試水結果、批次處理街廓資料。
- **顧問公司**：大數據分析統計、住戶與街廓分配管理、核定最終施工方案。
- **管理員**：系統監控、帳號權限管理、操作審計日誌。

## 🛠 系統技術
- **前端**：Vanilla JavaScript, HTML5, CSS3 (Glassmorphism 玻璃擬態設計)。
- **後端/資料庫**：Firebase Realtime Database。
- **圖示/圖表**：Lucide Icons, Chart.js。

## 🚀 部署資訊
本專案已部署於 GitHub Pages，支援手機與電腦跨裝置使用。
