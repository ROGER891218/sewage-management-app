# 污水接管意願管理平台 (Sewage Connection Management Platform)

![Version](https://img.shields.io/badge/Version-1.0.0-blue)
![Status](https://img.shields.io/badge/Status-Production--Ready-success)
![Tech](https://img.shields.io/badge/Tech-Vanilla_JS_/_Firebase-orange)

本平台由 **黎明工程顧問有限公司 (環工一組)** 開發與維護，專為污水下水道巷弄用戶接管之「意願調查」與「現場試水」所設計。透過即時雲端同步與智慧化決策支援，協助工程團隊高效管理複雜的住戶意願與技術資料。

## 📸 軟體畫面介紹 (Screenshots & Guide)

### 🔐 登入頁面

> 系統入口，支援四種身分角色登入。住戶可透過姓名、電話與身分證字號登入；廠商、顧問及管理員使用帳號密碼登入，並可勾選「記住帳號」。

![登入頁面](docs/screenshots/01_login.png)

**操作步驟：**
1. 從「選擇身分」下拉選單選擇您的角色（住戶 / 廠商 / 顧問 / 管理員）
2. **住戶端**：依序選擇案名 → 街廓 → 水系，填入姓名、電話（帳號）、身分證字號（密碼）與地址
3. **廠商/顧問/管理員**：輸入帳號與密碼，可勾選「記住帳號與密碼」方便下次登入
4. 點擊「**登入系統**」進入對應功能模組

---

### 🏠 住戶端 — 意願填寫

> 住戶登入後的主畫面，簡單直覺的表單介面讓住戶快速填寫前巷、後巷、側巷的接管意願，並可上傳現場照片供工程師參考。

![住戶端 - 意願填寫](docs/screenshots/02_resident.png)

**功能說明：**
| 功能 | 說明 |
|------|------|
| 🔘 接管意願選擇 | 分別針對**前巷、後巷、側巷**選擇「同意 / 不同意 / 待考慮」 |
| 📝 備註說明 | 可填寫額外的意見或特殊狀況 |
| 📷 照片上傳 | 直接拍攝或選擇現場環境照片上傳 |
| ✅ 提交意願 | 資料即時同步至雲端，工程團隊可立即查看 |

## 🧠 智慧化判接建議邏輯 (Decision Support Logic)

本平台內建專業工程判斷邏輯，自動輔助顧問工程師產出「建議接管方案」，實現數據驅動的決策：

1.  **水系意願自動加總**：
    *   系統以「水系」為最小分析單位，自動即時加總該水系內所有住戶的接管傾向。
2.  **過半數判定準則 (Majority Rule)**：
    *   當同水系內 **前巷接管意願 > 50%** 時，系統自動判定該區域為「前巷接管潛力區」，並產生對應建議。
3.  **技術與意願雙重校驗 (Synergy Validation)**：
    *   **技術連動**：將住戶意願與廠商回報的「試水資料」進行交叉比對。
    *   **一致性確認**：若原始設計規劃為前巷，且現場試水資料驗證可行，系統會自動核定該方案，確保「設計規劃」與「現場實況」達成一致。

## 🤖 AI 研發賦能 (AI-Enhanced Development)

本專案採用現代化 **AI 輔助開發模式**，體現了「人工智慧 + 工程專業」的完美結合：

*   **智慧邏輯轉化**：透過 AI 將複雜的專業污水判接準則轉化為精確的程式演算法，實現智慧化決策支援。

## 🌟 核心功能 (Core Features)

本系統針對四種核心角色提供專業的功能模組：

### 1. 🏠 住戶端 (Resident)
- **智慧表單填寫**：簡單直覺的介面，快速填寫接管意願。
- **多媒體上傳**：可直接上傳現場照片，供工程師參考。
- **數據透明化**：即時查看區域統計，提升住戶參與感。

### 2. 🛠️ 廠商端 (Contractor)
- **試水結果回報**：現場試水後立即上傳結果（通過/不通過/需補強）。
- **街廓資料管理**：批次處理住戶清單，減少紙本作業。

### 3. 📊 顧問公司 (Consultant)
- **大數據分析儀表板**：自動生成圖表，掌握各專案的接管意願比例。
- **自動判接建議**：依據過半數邏輯與試水結果，自動產出施工建議方案。

### 4. 🛡️ 管理員 (Administrator)
- **系統監控日誌**：即時追蹤所有用戶的操作行為與裝置資訊。
- **帳號權限管理**：嚴格控管存取權限，確保資料安全性。
