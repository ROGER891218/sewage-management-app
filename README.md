# 污水接管意願管理平台 (Sewage Connection Management Platform)

![Version](https://img.shields.io/badge/Version-1.0.0-blue)
![Status](https://img.shields.io/badge/Status-Production--Ready-success)
![Tech](https://img.shields.io/badge/Tech-Vanilla_JS_/_Firebase-orange)

本平台由 **黎明工程顧問有限公司 (環工一組)** 開發與維護，專為污水下水道巷弄用戶接管之「意願調查」與「現場試水」所設計。透過即時雲端同步與大數據分析，協助工程團隊高效管理複雜的住戶意願與技術資料。

---

## 📸 軟體畫面介紹 (Screenshots & Guide)

### 🔐 登入頁面

> 系統入口，支援四種身分角色登入。住戶可透過姓名、電話與身分證字號登入；廠商、顧問及管理員使用帳號密碼登入，並可勾選「記住帳號」。

![登入頁面](docs/screenshots/01_login.png)

**操作步驟：**
1. 從「選擇身分」下拉選單選擇您的角色（住戶 / 廠商 / 顧問 / 管理員）
2. **住戶端**：依序選擇案名 → 街廓 → 水系，填入姓名、電話（帳號）、身分證字號（密碼）與地址
3. **廠商/顧問/管理員**：輸入帳號與密碼，可勾選「記住帳號與密碼」方便下次登入
4. 點擊「**登入系統**」進入對應功能模組
5. 尚無帳號的廠商或顧問可點擊「**提交使用申請**」進行帳號註冊

---

### 🏠 住戶端 — 意願填寫

> 住戶登入後的主畫面，簡單直覺的表單介面讓住戶快速填寫前巷、後巷、側巷的接管意願，並可上傳現場照片供工程師參考。

![住戶端 - 意願填寫](docs/screenshots/02_resident.png)

**功能說明：**
| 功能 | 說明 |
|------|------|
| 🔘 接管意願選擇 | 分別針對**前巷、後巷、側巷**選擇「同意 / 不同意 / 待考慮」 |
| 📝 備註說明 | 可填寫額外的意見或特殊狀況 |
| 📷 照片上傳 | 直接拍攝或選擇現場環境照片上傳 |
| 📊 即時統計 | 住戶可查看所屬區域的整體意願比例統計圖 |
| ✅ 提交意願 | 資料即時同步至雲端，工程團隊可立即查看 |

---

### 🛠️ 廠商端 — 試水結果回報

> 廠商登入後，可依照所負責的街廓進行試水結果回報，減少紙本作業，提升現場效率。

![廠商端 - 試水回報](docs/screenshots/03_contractor.png)

**操作步驟：**
1. 使用頂部的**級聯式篩選器**選擇「案名 → 街廓 → 水系」，過濾出負責的住戶清單
2. 在表格中找到對應住戶，從「**試水結果**」下拉選單選擇：
   - ✅ **通過** — 試水合格
   - ❌ **不通過** — 試水失敗
   - ⚠️ **需補強** — 需進行管線補強後再測
3. 可在「備註」欄位填寫額外說明
4. 點擊「**儲存**」按鈕，結果即時同步至雲端

---

### 📊 顧問端 — 大數據分析儀表板

> 顧問公司可透過視覺化圖表即時掌握各專案的接管意願比例，支援多維度篩選與趨勢分析。

![顧問端 - 大數據分析](docs/screenshots/04_consultant.png)

**功能說明：**
| 功能 | 說明 |
|------|------|
| 🎯 級聯篩選 | 依**案名 → 街廓 → 水系**層層篩選，精確鎖定分析範圍 |
| 🥧 圓餅圖 | 自動生成意願比例圓餅圖（同意 / 不同意 / 待考慮） |
| 📈 趨勢圖 | 顯示提交數量隨時間的變化趨勢 |
| 📋 統計摘要 | 總住戶數、已填寫數、同意率等關鍵指標一目了然 |
| 📥 匯出功能 | 支援將分析結果匯出為 Excel 報表 |

### 🗺️ 管理端 — 街廓資料管理

> 管理員與顧問可在此維護街廓基礎地理資料，包含新增、編輯與刪除街廓，以及批次匯入住戶地址。

![管理端 - 街廓資料管理](docs/screenshots/06_admin_blocks.png)

**操作步驟：**
1. 在頂部表單填入「**案名**」、「**街廓名稱**」、「**水系**」
2. 點擊「**新增街廓**」將資料寫入系統
3. 下方表格顯示所有已建立的街廓，可直接進行**編輯或刪除**
4. 支援透過 **Excel 批次匯入**住戶地址清單

## 🌟 核心功能 (Core Features)

本系統針對四種核心角色提供專業的功能模組：

### 1. 🏠 住戶端 (Resident)
- **智慧表單填寫**：簡單直覺的介面，讓住戶快速填寫接管意願（前巷、後巷、側巷）。
- **多媒體上傳**：可直接拍攝並上傳現場環境照片，供工程師參考。
- **數據透明化**：住戶可即時查看所屬區域的總體意願統計，提升參與感。

### 2. 🛠️ 廠商端 (Contractor)
- **試水結果回報**：現場試水後立即上傳結果（通過/不通過/需補強）。
- **街廓資料管理**：可批次處理所負責街廓的住戶清單，減少紙本作業。

### 3. 📊 顧問公司 (Consultant)
- **大數據分析儀表板**：自動生成圓餅圖與趨勢圖，掌握各專案的接管意願比例。
- **住戶街廓分配管理**：彈性調整住戶所屬街廓與水系，支援地址批次匯入功能。
- **最終方案核定**：審核試水結果，產出最終施工建議清單。

### 4. 🛡️ 管理員 (Administrator)
- **系統監控日誌**：即時追蹤所有用戶的操作行為，包含 **IP 地址** 與 **操作裝置 (OS/Browser)**。
- **帳號權限管理**：嚴格控管不同角色的存取權限，確保資料安全性。
- **系統健康監測**：監控 Firebase 連線狀態、延遲 (Latency) 與記憶體使用量。

## 🚀 技術架構 (Technical Architecture)

- **前端介面**: 使用 Vanilla JavaScript 與 CSS3 打造，採用 **Glassmorphism (玻璃擬態)** 設計風格，兼具美觀與流暢度。
- **後端資料庫**: 採用 **Firebase Realtime Database**，實現跨裝置秒級資料同步。
- **響應式設計**: 完美適應電腦、平板與手機 (iOS/Android) 各種螢幕尺寸。
- **安全性**: 內建審計日誌系統，完整記錄登入資訊（包含 IP 與裝置資訊），防止非法竄改。

## 🛠️ 開發與部署 (Deployment)

1. **GitHub Pages**: 本專案已完全優化，支援 GitHub Pages 一鍵部署。
2. **Firebase 配置**: 資料庫設定已內嵌於 `index.html`，只需確保網域已列入 Firebase 的授權清單。
